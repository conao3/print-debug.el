Assisted printf debugging for Emacs. Insert debug print statements instantly with unique, trackable headers across multiple programming languages.

Inspired by [[https://github.com/sentriz/vim-print-debug][vim-print-debug]].

* Overview

When debugging, sometimes a quick print statement is all you need. print-debug.el makes this effortless by:

- Inserting language-appropriate print statements with a single keybinding
- Generating unique character sequences so you can identify each statement in the output
- Supporting multiple languages out of the box: Emacs Lisp, Go, Python, JavaScript, and C

* Installation

Requires Emacs 26.1 or later.

** Using leaf

#+begin_src emacs-lisp
(leaf print-debug
  :ensure t
  :bind (("s-j" . print-debug-insert)))
#+end_src

** Using use-package

#+begin_src emacs-lisp
(use-package print-debug
  :ensure t
  :bind (("s-j" . print-debug-insert)))
#+end_src

** Manual Installation

Clone this repository and add it to your load-path:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/print-debug.el")
(require 'print-debug)
(global-set-key (kbd "s-j") #'print-debug-insert)
#+end_src

* Usage

| Keybinding    | Description                                          |
|---------------+------------------------------------------------------|
| =s-j=         | Insert a debug statement at the current line         |
| =C-u s-j=     | Reset the header character to 'a' and insert         |
| =C-u C-u s-j= | Wrap the current line with two debug statements      |

Each inserted statement contains a unique header that increments with each use, making it easy to trace the order of execution in your output.

** Example Output

In an Emacs Lisp buffer, successive calls to =print-debug-insert= produce:

#+begin_src emacs-lisp
(message "+++ aaaaaaaaaa")
(message "+++ bbbbbbbbbb")
(message "+++ cccccccccc")
#+end_src

In a Python file:

#+begin_src python
print(f"+++ aaaaaaaaaa")
print(f"+++ bbbbbbbbbb")
#+end_src

* Configuration

** Customizing Templates

You can customize the print statement format for each file extension:

#+begin_src emacs-lisp
(setq print-debug-ext-template
      '((el . "(message \"+++ %S\")")
        (go . "fmt.Printf(\"+++ %S\\n\")")
        (py . "print(f\"+++ %S\")")
        (js . "console.log(`+++ %S`);")
        (c  . "printf(\"+++ %S\\n\");")))
#+end_src

Format specifiers:
- =%S= - Full header string (length controlled by =print-debug-header-length=)
- =%s= - Single character

** Header Length

Adjust the length of the debug header:

#+begin_src emacs-lisp
(setq print-debug-header-length 10)  ; default
#+end_src

** Major Mode Mapping

Map major modes to use specific templates:

#+begin_src emacs-lisp
(setq print-debug-major-mode-template
      '((c++-mode . c)
        (lisp-interaction-mode . el)))
#+end_src
